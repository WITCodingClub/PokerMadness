# Optional runtime data

Place declared read-only tables and their readable generation scripts here. Include the data actually needed at runtime so no network or large offline regeneration step is required during a match. Explain formats, generation parameters, and provenance in STRATEGY.md and on the form. Do not place credentials or executable encoded payloads here.

Non-neural precomputation is allowed under the draft rules. The eboard still needs to approve final archive and runtime-data size limits. This example has no data dependency.
